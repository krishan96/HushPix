Bits per character

Each character is eight bits, written one bit to each colour channel of three pixels. A ninth channel marks where the message ends.

How much fits

A character takes three pixels, so a 1920 × 1080 image holds 691,200 characters.

Which formats

Use PNG, BMP or TIFF. JPEG re-compresses the pixels and destroys the hidden bits.

How it reads the image

The tool reads one bit from each colour channel, three pixels per character, until it reaches the end marker. An image with no message gives no valid text.

What is steganography?

Steganography hides a secret message inside an ordinary file, such as an image, audio clip or document, so that its presence goes unnoticed. It is often paired with encryption. The article covers how it works, the main types (text, image, audio, video and network), its advantages, and how it differs from cryptography.

The mechanism in brief

Each character becomes eight bits. Each bit is written into the lowest bit of one colour channel, a change too small to see. A ninth channel marks where the message ends.
